# Title: Banc procédural fixe : 50 pistes (graines 0 à 49) dans eval.py + baseline best/

## Goal
Comparer les modèles sur les mêmes 50 pistes inconnues (critère A du goal), ce que l'éval procédurale actuelle ne garantit pas.

## Acceptance criteria
- [ ] `TimeAttackEnv.reset(track_seed=None)` : si `track_seed` est donné et que `procedural` est vrai, la piste est `generate_procedural_track(seed=track_seed)` ; sans argument, comportement inchangé. `GymTimeAttack.reset(options={"track_seed": n})` le transmet (reset(seed=..., options=...) reste compatible).
- [ ] `scripts/eval.py --bench` : 50 épisodes, l'épisode k utilise la piste de graine k (k = 0..49), 3 tours par défaut (`--laps` respecté), aucun hasard hors piste (même résultat à chaque lancement). Incompatible avec `--static`/`--no-static`. L'entrée de `metrics.json` contient `"bench": true`, `"static": false`, `"episodes": 50`, et les champs habituels (finish_rate, mean_wall_hits, clean_rate…).
- [ ] Les options existantes (`--static`, `--no-static`) donnent exactement le même résultat qu'avant (mêmes graines).
- [ ] Baseline : `best/best.zip` mesuré avec `--bench` (3 tours) et ajouté à `metrics.json` ; chiffres dans `docs/BENCH_V2.md` (nouveau, court : commande, résultat, date). Mesurer aussi la liste des graines où best/ choque le plus (top 5) dans ce document.
- [ ] Test dans `tests/test_eval.py` ou `tests/test_env.py` : deux resets avec `track_seed=7` donnent la même piste (`track.seed`, mêmes `spline_points`) ; `track_seed=7` et `8` diffèrent.
