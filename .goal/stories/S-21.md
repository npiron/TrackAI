# Title: Récompense « simple » optionnelle pour GymTimeAttack (progression + temps + chocs)

## Goal
Disposer d'une récompense PPO propre (progression le long de la piste par pas + petite pénalité de temps + forte pénalité par choc), activable par option, pour que l'affinage PPO d'E6 ne soit pas pollué par les termes hérités (alignement, vitesse, fantôme, urgence).

## Acceptance criteria
- [ ] `GymTimeAttack(..., reward_mode="legacy"|"simple")`, défaut `"legacy"` : récompense et tests existants strictement inchangés.
- [ ] En `"simple"` : récompense par pas = `k_prog * (progression_t - progression_{t-1})` − `time_penalty` + `wall_penalty * nouveaux_chocs` (+ bonus terminal de fin de course s'il existe déjà dans `reward` de l'env ; le dire). `progression` = abscisse curviligne projetée sur la ligne centrale (pas la distance au prochain checkpoint) ; elle est monotone en avant, la marche arrière donne une valeur négative, pas de récompense hors piste. Constantes nommées en tête de fichier (défaut `k_prog` tel qu'un tour de piste fixe ≈ +100 ; `time_penalty` 0,01 ; chocs via `wall_penalty` existant).
- [ ] `info["reward_components"]` reste présent et somme au total.
- [ ] Un test pytest : sur la piste fixe avec le pilote programmé (`scripts/heuristic_lap.py`), la somme des récompenses d'un tour ≈ `k_prog * longueur_ligne_centrale` − `time_penalty * pas` (tolérance 5 %), et un choc retire exactement `|wall_penalty|`.
