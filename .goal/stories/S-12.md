# Title: eval.py, imitate.py et robust_eval.py gèrent obs v1 et v2

## Goal
Pouvoir mesurer les anciens modèles (v1) et entraîner/mesurer des modèles v2 avec les mêmes scripts (étape 1 du goal, préparation d'E5).

## Acceptance criteria
- [ ] `eval.py` choisit `obs_version` automatiquement d'après `model.observation_space.shape` (14 → 1, taille v2 → 2) ; option `--obs-version {1,2}` pour forcer (utile pour `random`/`heuristic`, défaut 1). Les modèles v1 existants (best/, s5_a) donnent exactement les mêmes chiffres qu'avant (relancer l'éval statique 20 ép. de best/ : mêmes chiffres que la mesure S-13 / docs/TEACHER_V2.md, nouvelle physique).
- [ ] `heuristic` dans eval.py reçoit toujours une obs v1 (via `ta.obs_v1()`), même si l'env est v2.
- [ ] `imitate.py` : option `--obs-version {1,2}` (défaut 1) ; l'env, la collecte (`collect`) et le VecNormalize utilisent v2 ; l'étiquette du professeur est calculée avec `heuristic_action(ta.obs_v1(), env.ta)` ; la politique DAgger voit l'obs v2. Le `--init` v1 reste possible (obs_version déduite du modèle).
- [ ] `robust_eval.py` : même détection automatique que eval.py.
- [ ] Test (tests/test_imitate.py ou test_eval.py) : un mini BC v2 (quelques épisodes courts, 1 époque) tourne, sauve, et eval.py recharge ce modèle sans erreur ; forme des obs collectées = taille v2.
- [ ] Mini-mesure : un modèle v2 jetable (BC 10 épisodes, mix statique/procédural) évalué avec `--bench` tourne de bout en bout (résultat sans importance, pas ajouté à metrics.json ; utiliser `--metrics /tmp/x.json`).

## Verify
- `SDL_VIDEODRIVER=dummy .venv/bin/python -m pytest -q --ignore=tests/test_e2e_training.py` → tout passe.
- `SDL_VIDEODRIVER=dummy .venv/bin/python scripts/eval.py --model data/models/best/best.zip --static --laps 3 --episodes 20 --seed 0 --metrics /tmp/chk.json` → mêmes chiffres que la mesure statique de best/ faite en S-13 (nouvelle physique : ~19,48 s, ~22 chocs avant S-13 ; l'ancien 15,46 s est périmé).
