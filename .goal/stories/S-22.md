# Title: scripts/ppo_finetune.py : PPO depuis best/ avec perte d'imitation auxiliaire décroissante

## Goal
Pouvoir affiner `data/models/best/best.zip` (v2) par PPO sans oubli : lr faible, petit clip, 8 environnements parallèles en mix fixe/procédural, avec une perte d'imitation auxiliaire (cross-entropy sur des états étiquetés par le professeur) dont le coefficient décroît.

## Acceptance criteria
- [ ] Nouveau `scripts/ppo_finetune.py` : options `--init` (modèle .zip + `_vecnormalize.pkl`, obs détectée via `detect_obs_version`), `--timesteps`, `--lr` (défaut 3e-5), `--clip` (défaut 0,05), `--n-envs 8` (`SubprocVecEnv`, ou `DummyVecEnv` si `--n-envs 1`), `--aux-coef0` (défaut 1,0) décroissant linéairement jusqu'à 0 en fin d'entraînement, `--aux-episodes` (collecte du jeu de données professeur via `imitate.collect` avec `policy=` du modèle initial, DAgger-like, `hit_weight` 10, `--laps 3`), `--reward-mode simple`, `--wall-penalty -50`, `--out`, `--seed`, `--max-minutes` (arrêt propre, défaut 28, sauvegarde du dernier état).
- [ ] Environnements : alternance fixe / procédural graines ≥ 1000 (même règle que `collect`, banc 0-49 jamais utilisé en entraînement) ; VecNormalize chargé depuis le modèle initial avec `training=False` pour les observations (statistiques gelées : le professeur et le banc doivent voir la même normalisation) et `norm_reward=False`.
- [ ] La perte auxiliaire est ajoutée à chaque mise à jour (callback ou sous-classe de `PPO.train`) : un test pytest minimal (1 000 pas, `--n-envs 1`, `--aux-episodes 2`) vérifie que le script tourne, sauve `.zip` + `_vecnormalize.pkl`, et que `--aux-coef0 0` donne un coefficient nul.
- [ ] Journal d'entraînement imprimé tous les ~20 000 pas : coef aux, chocs/épisode, temps de tour moyen, entropie.
- [ ] Le modèle sauvé se recharge et s'évalue avec `scripts/eval.py` sans option (obs v2 détectée).

## Verify
- `.venv/bin/python -m pytest -q` → vert.
- `SDL_VIDEODRIVER=dummy .venv/bin/python scripts/ppo_finetune.py --init data/models/best/best.zip --timesteps 20000 --n-envs 2 --aux-episodes 4 --out data/checkpoints/ppo_ft_smoke` → termine, fichiers créés.
- `.venv/bin/python scripts/eval.py --model data/checkpoints/ppo_ft_smoke.zip --static --episodes 3 --seed 0 --laps 3` → s'exécute.
